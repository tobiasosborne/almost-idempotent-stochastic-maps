\begin{proofbox}{Extended th\_main\_ext assembly: there are universal C\_E < ...}
\step{1} Extended th\_main\_ext assembly: there are universal C\_E < infinity and epsilon\_E > 0 such that every finite-dimensional extended epsilon-C*-algebra A, for 0 <= epsilon <= epsilon\_E, is carried by one extended C\_E*epsilon-isomorphism v:B->A from a finite-dimensional C*-algebra, with constants independent of dimension, amplification level, and block data. \steptag{validated} \\[6pt]
\step{1.1} Invoke lem-maincb-structural-assembly and fix its universal MAIN-CB witness-ledger datum W. Define C\_E := W.c0\_cb*W.K\_call and epsilon\_E := W.epsilon\_MAIN. The final clause of lem-maincb-structural-assembly states that these two quantities are finite positive universal witnesses; therefore C\_E < infinity and epsilon\_E > 0, with neither depending on dimension, amplification level, block count, or block dimensions. \steptag{validated} \\[4pt]
\step{1.2} Let A be an arbitrary finite-dimensional extended epsilon-C*-algebra and let 0 <= epsilon <= epsilon\_E. Using epsilon\_E = W.epsilon\_MAIN from node 1.1, lem-maincb-structural-assembly supplies a finite-dimensional C*-algebra B = direct\_sum\_C M\_\{|C|\} and one extended W.c0\_cb*W.K\_call*epsilon-isomorphism v:B->A (indeed also satisfying its unused unit estimate). Substituting C\_E = W.c0\_cb*W.K\_call, this is one extended C\_E*epsilon-isomorphism v:B->A. \steptag{validated} \\[4pt]
\step{1.3} By the registered definition def-extended-delta-inclusion, an extended C\_E*epsilon-isomorphism is a single bijective linear map v whose every amplification 1\_\{M\_n\} tensor v is a C\_E*epsilon-inclusion. Thus the map in node 1.2 carries A at all amplification levels with the same constant; node 1.1 makes that constant and epsilon\_E universal and independent of all dimension and block data. Since A and epsilon in node 1.2 were arbitrary, the asserted universal conclusion follows. \steptag{validated} \\[4pt]
\end{proofbox}
