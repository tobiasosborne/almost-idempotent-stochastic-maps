\begin{proofbox}{Weighted minimum bound: let p\_1, ..., p\_m be positive rea...}
\step{1} Weighted minimum bound: let p\_1, ..., p\_m be positive reals with sum\_i p\_i = 1 and let n\_1, ..., n\_m be real numbers; then min over i in \{1, ..., m\} of n\_i <= sum\_i p\_i * n\_i. \steptag{validated} \\[6pt]
\step{1.1} There is an index k in \{1, ..., m\} such that n\_k = min over i in \{1, ..., m\} of n\_i. \steptag{validated} \\[4pt]
\step{1.2} For this index k, n\_k <= n\_i for every i in \{1, ..., m\}. \steptag{validated} \\[4pt]
\step{1.3} For the index k supplied by nodes 1.1 and 1.2, so that n\_k <= n\_i for every i in \{1, ..., m\}, we have p\_i * n\_k <= p\_i * n\_i for every i in \{1, ..., m\}. \steptag{validated} \\[6pt]
\step{1.3.1} By validated node 1.2, for every i in \{1, ..., m\}, n\_k <= n\_i for the chosen index k. \steptag{validated} \\[4pt]
\step{1.3.2} For an arbitrary i in \{1, ..., m\}, the root hypothesis gives p\_i > 0; multiplying n\_k <= n\_i from node 1.3.1 by this positive real preserves the inequality, hence p\_i * n\_k <= p\_i * n\_i. Since i was arbitrary, the inequality holds for every i. \steptag{validated} \\[4pt]
\step{1.4} Summing these inequalities over i gives (sum\_i p\_i) * n\_k <= sum\_i p\_i * n\_i. \steptag{validated} \\[4pt]
\step{1.5} Since sum\_i p\_i = 1 and n\_k is the minimum, the preceding inequality is exactly min\_i n\_i <= sum\_i p\_i * n\_i. \steptag{validated} \\[4pt]
\end{proofbox}
