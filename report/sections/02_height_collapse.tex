\section{Height collapse}\label{sec:height-collapse}

\begin{observation}[\texttt{obs-height-collapse}]\label{obs:height-collapse}
Let $P$ be an exact signed idempotent with $0<\negmass(P)\le\tfrac14$, nonempty
visible set $\vis(P)$, and a hidden top vertex $v$ of height
$\height=\distone(p_v,\conv\vis)$ maximal among the rows. Then the invisible
mass $\sigma_v$ and the row negative mass $\nu_v$ satisfy
\[
  \height\,(1-\sigma_v)\;\le\;\nu_v\,(2+4\negmass).
\]
\end{observation}

\noindent\textbf{Registry contract (verbatim).}
\contractquote{Height collapse: for an exact signed idempotent P with 0 < delta(P) <= 1/4, nonempty visible set W(P), and hidden top vertex v (height H = dist_1(p_v, conv W) maximal among rows), the invisible mass sigma_v and the row negative mass nu_v satisfy H * (1 - sigma_v) <= nu_v * (2 + 4*delta).}

\noindent\textbf{Status.} \texttt{proved}; \texttt{af: validated}.
This is one of the rigorous in-repo results.

\noindent\textbf{Proof tree.} The registry shard records a 19-node
adversarial tree with root \texttt{validated} and taint \texttt{19/19
clean}.  The export is
\texttt{proofs/obs-height-collapse/export.md}.  Earlier compound

section records only the validated inequality.

\noindent\textbf{Role in the chain.} This result explains why invisible
mass alone does not finish the Kernel/\texttt{(EX)} route: height is
controlled only after pricing the complementary mass.  A future
dimension-free cap on the relevant invisible mass would combine with
this inequality, but that cap is not proved here.
