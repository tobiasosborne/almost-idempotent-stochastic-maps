\section{Negative-part subadditivity}\label{sec:negpart-subadditive}

\begin{lemma}[Registry contract for \texttt{lem-negpart-subadditive}]
\label{lem:negpart-subadditive}
\contractquote{Negative-part subadditivity: for all vectors x and y in R^d, writing n(w) = sum_l max(-w(l), 0), one has n(x + y) <= n(x) + n(y).}
\end{lemma}

\noindent\textbf{Status.} \texttt{proved}; \texttt{af: validated}.
This is one of the rigorous in-repo results.

pre-factored \emph{before} elevation, applying the balloon lesson from

\noindent\textbf{Role in the chain.} Pre-factored dependency of

pointwise subadditivity (with nonnegative homogeneity, which is
