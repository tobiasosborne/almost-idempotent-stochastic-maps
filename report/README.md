# report/ — the internal RIGOROUS lab-book (sharded)

`report/main.tex` (+ `sections/NN_<slug>.tex`) is the internal LaTeX lab-book that reproduces the
**rigorous spine** of the argument: each Definition/Theorem here is either byte-matched to a `refs/`
source or `af`-validated (L0), and carries a row in `PROVENANCE.md`. This is **not** where numerics or
heuristics go — those live in `runs/` (numerical, L3) and the `argument/` shard bodies, tagged
non-rigorous. The ingested classical-portfolio (`docs/ingest/`) is the object of re-establishment, not
reproduced here until a result clears L0.

- `main.tex` — master; preamble + macros + an ordered `\include{sections/NN_<slug>}` list ONLY (no body
  prose; `check-report-shards.sh` enforces master purity).
- `sections/NN_<slug>.tex` — one shard per result/topic (~≤200 lines, hard guard 280), each opening with a
  header block:

  ```
  % SHARD-ID: AISM-NN-SOME-LABEL
  % SHARD-TITLE: Human title
  % SHARD-SUMMARY: sentence 1 (mirrored verbatim in SHARD_CATALOG.md)
  % SHARD-SUMMARY: sentence 2
  % SHARD-KEYWORDS: comma, separated, keywords
  \section{Human title}\label{sec:...}
  ```

- `generated/defs/` — the definitions layer, GENERATED from `definitions/*.md` by
  `scripts/gen-report-defs.py` and `\input` by `sections/00a_definitions.tex`. Never
  hand-edit; re-render with `python3 scripts/gen-report-defs.py` (the gate runs `--check`).
- `generated/dag/*.tex` — GENERATED by `scripts/gen-report-dag.py` from `argument/lemmas/*.md`;
  `\input` by `sections/39_argument_dag.tex` (+ `generated/dag/preamble.tex` from the master
  preamble). Never hand-edit; `python3 scripts/gen-report-dag.py --check` is a hard gate.
  Crosslink anchors: `dag:<registry-id>`, `dag:<def-id>`, `dag:phase:<key>` — link with
  `\dagref{lem-prh}`, `\dagdef{def-height}`, `\dagphase{comp}{the COMP/H-CB tower}`.
- `generated/stats/*.tex` — the campaign-statistics layer, GENERATED by
  `scripts/gen-report-stats.py` from the committed snapshot `generated/stats/campaign-extract.json`;
  `\input` by `sections/40_campaign_statistics.tex` (body) and by the master preamble/frontmatter
  (`preamble.tex`, `headline.tex`). Never hand-edit; `python3 scripts/gen-report-stats.py --check`
  is a hard gate. See "Generated layers" below.
- `SHARD_CATALOG.md` — the search index (id + title + summaries + keywords per shard); gated.
- `PROVENANCE.md` — the audit ledger (source registry + per-claim rows); gated by `check-provenance.py`.
- `Makefile` — `make` → `latexmk -pdf main.tex` → `main.pdf`.

Build: `cd report && make`. The gate compiles into `report/.build/` so `main.pdf` is never mutated
mid-check.

## Generated layers (`report/generated/`)

Some shards are **thin**: they carry only a `\section` plus an `\input` of a machine-generated body
under `report/generated/<layer>/`. Never hand-edit anything under `report/generated/` — a `--check`
mode in the producing script byte-compares it against a fresh render inside `scripts/check-all.sh`.

| Layer | Producer | Consumed by | Freshness gate |
|-------|----------|-------------|----------------|
| `report/generated/defs/` | `scripts/gen-report-defs.py` | `sections/00a_definitions.tex` | `python3 scripts/gen-report-defs.py --check --dag-anchors` |
| `report/generated/dag/` | `scripts/gen-report-dag.py` | `sections/39_argument_dag.tex` + `main.tex` preamble | `python3 scripts/gen-report-dag.py --check` |
| `report/generated/stats/` | `scripts/gen-report-stats.py` | `sections/40_campaign_statistics.tex` (body) + `main.tex` preamble/frontmatter | `python3 scripts/gen-report-stats.py --check` |

`gen-report-stats.py` is split into an **extract** half (mines the live repositories into the
committed snapshot `report/generated/stats/campaign-extract.json`) and a **render** half (snapshot →
`.tex`). Only rendering is gated, so the gate is stable across ordinary commits; refreshing the
numbers is the deliberate `--extract` step. Rationale and staleness semantics are stated in the
generated section's own colophon.
