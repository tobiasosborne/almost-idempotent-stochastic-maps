# `docs/` — history, plans, and the inherited record

Nothing in this directory is a rigour rung. Claims live in `argument/`; `docs/` records how they got
there, what was tried, and what had to be withdrawn.

| Path | Kind | What it holds |
|---|---|---|
| `docs/worklog.md` | append-only | dated session history, 90 entries. The narrative record; `HANDOFF.md` is rewritten each session, this file is never rewritten. |
| `docs/LEARNINGS.md` | append-only ledger | **retracted claims** — 8 dated entries, each naming what was claimed, why it was wrong, and what caught it. |
| `docs/plans/` | dated proposals + designs | 68 files and 30 subdirectories. Includes the live proof sketch (below) and the per-wave design/audit packages. `docs/plans/CHANGELOG.md` is the rolling changelog for the proof-sketch series. |
| `docs/plans/CURRENT.md` | generated pointer | one link, regenerated by `scripts/gen-current-pointer.py`, aimed at the lexicographically-latest `docs/plans/*top-down-proof-sketch*` file. Currently `2026-08-09-top-down-proof-sketch-v53.md`. |
| `docs/waves/` | early wave artifacts | 95 files and 12 subdirectories, `2026-07-02-A1-ex-chart-scoping.md` through `2026-07-16-W70-artifacts/`. |
| `docs/ingest/` | inherited record | the copied `classical-portfolio` campaign from `../almost-idempotent-positive-maps`. Read-mostly; **never citable as rigorous** (L1). |
| `docs/audits/` | one-off audit | `2026-07-04-operational-audit.md`, the four-lane operational audit. |
| `docs/recon/` | one-off recon | `2026-07-05-open-mechanism-recon.md`, a breadth-first sketch of the open mechanisms. |
| `docs/lit-review/` | one-off sweep | `2026-07-04-literature-sweep.md`. |
| `docs/tooling-feedback/` | outbound notes | `AF-FEEDBACK.md`, `FR-FEEDBACK.md` — feedback to the external `af` and `fr` tools. |

## The proof sketch series

`docs/plans/` holds **53** files matching `*top-down-proof-sketch*`, v1 (2026-07-04) through v53
(2026-08-09). Only the latest is live — `CURRENT.md` names it. The other 52 are **kept on purpose**:
commit messages, registry shards and worklog entries cite them by file *and line number*, so deleting a
superseded sketch would break citations that were correct when written. Supersession is by adding a new
dated file, never by editing an old one.

## Where wave artifacts live

A wave is one subagent dispatch (see `GLOSSARY.md`). Early waves wrote into `docs/waves/`. That
directory's last entry is `2026-07-16-W70-artifacts/`; from roughly W73 onward the artifacts were
written into `docs/plans/` instead, as dated `*-artifacts/` or `*-design/` subdirectories — for example
`docs/plans/2026-07-22-W73-artifacts/`, `docs/plans/2026-07-27-F0-ASSEMBLY-design/`,
`docs/plans/2026-08-09-W140-REPORT-SYNC/`. The move was not announced in a migration note; both
locations are live and neither is a mirror of the other. Search both.

## The retraction ledger

`docs/LEARNINGS.md` states its own purpose in its header:

> UPDATE POLICY: append a dated entry when an in-repo claim is retracted. A retraction here is a
> SUCCESS of the rigour machinery, not an embarrassment.

It covers only claims *this* repo asserted and then withdrew. Inherited routes that were refuted before
they got here are recorded instead as dead-route certificates in `FINDINGS.md`, which also carries the
live gotchas.
