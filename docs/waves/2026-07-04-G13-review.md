## Section 1: c<0 Sign-Agnostic Transform

Verdict: APPROVE.

The derivation is sign-agnostic. From

```text
p_j = c p_{u_s} + sum_{q != s} d_q p_{u_q},   c != 0,
```

one gets

```text
p_{u_s} = c^{-1} p_j - sum_{q != s} (d_q/c) p_{u_q}.
```

Substitution into `p_i = a_s(i)p_{u_s} + sum_{q != s} a_q(i)p_{u_q}` gives

```text
a_s^j(i) = a_s(i)/c,
a_q^j(i) = a_q(i) - a_s(i)d_q/c.
```

No inequality or sign division is used, so there is no `c<0` slip.

## Section 2: c<0 Pointwise Import Bound

Verdict: APPROVE.

With `c=-k<0`, `x=a_s(i)`, `y=a_t(i)`, `z=a_r(i)`, the new inner expression is

```text
Y = x^+/k + (-y + x d_t/c)^+ - 1 + z - x d_r/c.
```

The identity

```text
(-x/c)^+ = x^+/k
```

is correct. The four cases for

```text
(-y+w)^+ <= y^- + w^+
```

are also correct. Combining them gives

```text
Y <= X + R^-_{r,j}(i)
```

with

```text
R^-_{r,j}(i) =
  a_s(i)^+/(-c) - a_s(i)^-
  + (a_s(i)d_t/c)^+ - a_s(i)d_r/c.
```

Then monotonicity of positive part plus `(A+B)^+ <= A^+ + B^+` gives

```text
E_r^j(i) <= E_r(i) + (R^-_{r,j}(i))^+.
```

The split is correct:

```text
x >= 0:  R^- = x * (1 + d_t^- + d_r)/(-c),
x <  0:  R^- = x^- * ((d_t^+ - d_r)/(-c) - 1).
```

Therefore

```text
I^-_{r,j}(U)
 <= ((1+d_t^-+d_r)^+/(-c)) A_{r,s}
    + (((d_t^+-d_r)/(-c)-1)^+) B_{r,s}.
```

As noted above, this is equality under the displayed split and the standard definitions of `A_{r,s}` and `B_{r,s}`; the weaker inequality is valid.

## Section 3: Minimality Analysis

Verdict: APPROVE.

(a) Volume-inadmissible carriers: correct. If `|a_s(i)| m_U < 1/2`, then `V_i` is not in the theta-half comparison class, so Phi-minimality gives no comparison. The volume-only estimate is exactly

```text
a_s(i)^- < 1/(2m_U),
B_thin < (1/(2m_U)) sum_i beta_r(i)^+
       <= (1/(2m_U))(1+delta(P)).
```

Since `m_U >= 1/2`, this yields only an `O(1)` bound, not `O(delta)`.

(b) Psi-blocked admissible carriers: correct. For a pivot-removing chart replacing `u_s` by `i`, the new left-inverse row for coordinate `s` is `P_i`, while the `c<0` import bound controls only transverse rows whose left-inverse rows remain `P_{u_q}`. The Psi block therefore genuinely escapes this transverse import bound.

(c) Gamma-blocked admissible carriers: correct. If for some `q != s`,

```text
Phi_s(U) <= Phi_q(V_i),
```

then Section 2 gives

```text
Phi_q(V_i) <= Phi_q(U) + I^-_{q,i}(U),
```

so

```text
Phi_s(U) - Phi_q(U) <= I^-_{q,i}(U).
```

This is only a lower forcing on the import term, not an upper charge of the carrier mass.

## Section 4: Conditional Proof

Verdict: APPROVE.

`NSC(K0)` is stated as a single inequality:

```text
B_{r,s}
 <= K0 * sum_{i: beta_r(i)>0, a_s(i)<0} beta_r(i)^+ nu_i(P).
```

No hidden compound assertion is embedded in the formula.

The reduction is correct. Since row `u_r` has sum `1`,

```text
sum_i beta_r(i)^+ = 1 + sum_i beta_r(i)^- <= 1 + delta(P),
```

because `sum_i beta_r(i)^-` is the negative mass of row `u_r`. Also `nu_i(P) <= delta(P)` for every row by definition of `delta(P)`. Thus

```text
B_{r,s} <= K0 delta(P) sum_i beta_r(i)^+
         <= K0(1+delta(P))delta(P)
         <= (5K0/4)delta(P)
```

under `delta(P) <= 1/4`.

The compatibility statement with the `0.771` data point is correct: the maximizing run has exact ratio

```text
B/delta = 8400000/10897843.
```

So any unconditional `B <= K delta` theorem covering that instance must have `K` at least that value.
