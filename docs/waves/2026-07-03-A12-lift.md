# Arm A Wave 12: The Lift From Fan Payment To The Horn

Target read verbatim from `argument/lemmas/conj-degenerate-payment.md`: at a
theta-`1/2` `Phi`-argmin chart `U`, for pivot `s`, the Schur-degenerate set
`D_s` should satisfy

```text
sum_{j in D_s} beta_s(j) E_s(j) <= 2 delta(P).
```

The constant `2` is no longer the right hill to defend. The validated discrete
input is the D-restricted fan lemma with sharp constant

```text
C_DRF = 2 + sqrt(2).
```

This wave scopes the exact lift errors and isolates the remaining transport
statement.

## T1. Coordinate Half

Fix a chart `U=(u_1,...,u_k)` and pivot `s`. Put `d=k-1`,
`beta_j=beta_s(j)=P_{u_s j}`, and write the transverse coordinate block

```text
x_j = (a_t(j))_{t != s},        lambda_j = lambda_s(j) = sum_{t != s} a_t(j).
```

The fan model wants coordinate-sum-zero vectors. The canonical recentered lift is

```text
w_j = x_j - (lambda_j/d) * 1_d.
```

Then `sum_l w_j(l)=0`. The target's `mu` and `E` are exactly

```text
mu_j = n(x_j) = sum_l max(-w_j(l) - lambda_j/d, 0),
E_j  = max(mu_j - lambda_j, 0),
n(w_j) = sum_l max(-w_j(l), 0).
```

Consequently the lambda correction is explicit:

```text
if lambda_j >= 0:   n(w_j) - 2 lambda_j <= E_j <= n(w_j),
if lambda_j <= 0:   n(w_j) <= E_j <= n(w_j) + 2(-lambda_j).
```

Equivalently `|E_j-n(w_j)| <= 2|lambda_j|`. On an active row (`E_j>0`) one also
has the crude but useful bounds

```text
E_j <= 2 mu_j,        n(w_j) <= 2 mu_j.
```

So the lambda defect is not a mystery term; it is the only reason `E_j` is not
the fan distance `n(w_j)`. In all reduced fan rows `lambda_j=0`, hence
`E_j=n(w_j)=mu_j` exactly. [T1]

### Positive-beta barycenter

The harmonic identities give, for every transverse coordinate,

```text
sum_j beta_j a_t(j) = 0.
```

Together with `(DEF)`, `sum_j beta_j lambda_j=0`, this gives the exact signed
centered barycenter identity

```text
sum_j beta_j w_j = 0.                                  (1)
```

Let `B_+=sum_j beta_j^+` and `B_-=sum_j beta_j^-`. Since the pivot row has row
sum one, `B_+=1+B_-`; by the negative-mass bound, `B_- <= delta(P)`. The
positive-beta barycenter is therefore

```text
b_+ = (1/B_+) sum_j beta_j^+ w_j
    = (1/B_+) sum_j beta_j^- w_j.                       (2)
```

Thus the barycenter defect is sourced exactly by the negative part of the pivot
row. Quantitatively,

```text
B_+ n(b_+) = n(sum_j beta_j^+ w_j)
           = n(sum_j beta_j^- w_j)
          <= sum_j beta_j^- n(w_j).                     (3)
```

This is the precise place where "signed harmonicity" differs from the fan
hypothesis. The defect is small in the zoo, but (3) alone is not a
dimension-free theorem because `n(w_j)` on beta-negative rows still needs a
transport bound. [T1/T2]

### Perturbed DRF Variant

The validated `lem-fan-payment-restricted` applies to zero-barycenter positive
families. The following perturbation is immediate from the same machinery.

Let `(w_i,p_i)` be coordinate-sum-zero, `sum_i p_i=1`, with barycenter `b`. Let
`w_*` be a support minimizer of `v -> sum_i p_i n(w_i-v)`, and let
`A={i:n(w_i-w_*)>0}`. Applying DRF to `z_i=w_i-b` gives

```text
sum_{i in A} p_i n(w_i-w_*)
 <= C_DRF * ( sum_{i in A} p_i n(w_i) + p(A) n(b) ).
```

In unnormalised beta notation this becomes

```text
sum_{i in A} beta_i^+ n(w_i-w_*)
 <= C_DRF * ( sum_{i in A} beta_i^+ n(w_i) + B_+ n(b_+) ).       (4)
```

The minimizer condition is automatic in the certified fan templates. In a
general chart it is an extra lift condition: `Phi`-argmin over charts does not
literally say that the pivot row is the positive-beta fan median unless the
illegal Schur-swap obstruction has been accounted for. [T1/T2]

Combining the exact lambda relation with (4) yields the honest coordinate
package

```text
sum_{j in D_s} beta_j^+ E_j
 <= C_DRF * ( sum_{j in A} beta_j^+ n(w_j) + B_+ n(b_+) )
    + 2 sum_{j in D_s} beta_j^+ (-lambda_j)_+.                  (5)
```

Here `A={j:n(w_j)>0}` is the DRF active set for the positive-beta family. The
identification `A=D_s` holds in the clean reduced fan templates. In a general
chart it is another lift condition: legal rows or rows with `E_j=0<n(w_j)` can
make `A` larger than the Schur-degenerate payment set. Thus (5) is directly a
payment-horn estimate only in the all-degenerate/fan-like regime, or after a
separate restriction argument. [T1/T2]

On the actual payment set `D_s`, `n(w_j) <= 2 mu_j`. Thus a proof may either:

1. use the crude direct pointwise lift `E_j <= 2 mu_j`, or
2. use the sharper DRF lift (5), paying the barycenter and negative-lambda
   source terms and the `A` versus `D_s` restriction mismatch.

The discrete fan lemma is no longer the obstruction. The obstruction is sourcing
the right transverse mass terms from `delta(P)`. [T1/T2]

## T2. Transport Half

The remaining useful target is not another fan inequality. It is a transverse
transport estimate for the Schur-degenerate rows:

```text
M_D(s) := sum_{j in D_s} beta_s(j)^+ mu_s(j) <= C_tr * delta(P).     (TT)
```

A single af-elevatable sentence:

```text
Degenerate transverse transport: under the hypotheses of
conj-degenerate-payment, there is a universal constant C_tr such that for every
pivot s, sum_{j in D_s} max(beta_s(j),0) * sum_{t != s} max(-a_t(j),0)
<= C_tr * delta(P).
```

This is the arm-D transverse coefficient tax restricted to the Schur-degenerate
set and to a theta-`1/2` `Phi`-argmin. [T2]

Why this is the true transport problem:

```text
a_t(j) = sum_l P_{jl} a_t(l)             row reproduction
beta_s(l) = sum_j beta_s(j) P_{jl}       beta row stationarity
sum_j beta_s(j) a_t(j) = 0               harmonic identity
```

For a row `j in D_s`, negative transverse mass in `a_t(j)` must be inherited
through the signed row `P_j*`. The row negative mass `nu_j` can pay for pushing
an expectation below the positive hull, but positive entries of `P_j*` can also
import negative coordinates from other rows. Controlling that import without
summing over transverse coordinates is the transport half.

The Schur-degenerate slab helps but does not solve it. From one-row minors one
gets `|a_t(j)| <= 1/2` on the tested degenerate coordinates, yet this only gives
`mu_j <= (k-1)/2`, which is dimension-dependent and useless. The desired handle
must be clone-invariant and aggregate in `mu`, not coordinate-counting. [T1/T2]

Exact transport ratios in the zoo:

| witness | `M_D/delta` |
|---|---:|
| transverse `a=1/8` | `1` |
| transverse `a=1/4` | `1` |
| no-center path `k=6` | `3/2` |
| no-center path `k=8` (A8 context) | `5/3` |
| one-anchor star `foreign=9` | `23/16` |
| repeated star `anchors=3` (A8 context) | `11/8` |
| A7 shared-midpoint path `f=5` (A8 context) | `3/2` |
| balanced staircase `m=5,a=1/16` | `60000121/60000000` |
| sigma-cap B | `0` |

So yes: empirically the restricted transport ratio is bounded by about `2` on
the current zoo. This is evidence only. [T0/T1]

If (TT) holds, the payment horn follows immediately with a relaxed constant
even without DRF, because `E_j <= 2 mu_j` on `D_s`:

```text
sum_{j in D_s} beta_j^+ E_j <= 2 C_tr delta(P).
```

The DRF-composed route gives potentially better constants in the fan-like
lambda-zero regime, but in the general chart it also needs the beta-sign
barycenter source `Bsrc` and the negative-lambda source `L_D` controlled by the
same transport mechanism. [T1/T2]

## T3. Verdict

**Remaining obstruction.** The fan inequality is closed. The live obstruction is
the restricted transport/source statement (TT), or slightly more robustly the
source package

```text
M_D(s) + B_+ n(b_+) + L_D(s) <= C_src delta(P).
```

The sharpest single sentence to elevate later is (TT); the source-package
version is safer for composing through the perturbed DRF lift. [T2]

**Wall shape.** The all-row version of (TT) is essentially arm D's old
transverse coefficient tax and is wall-shaped. The `D_s` restriction plus
theta-`1/2` argmin may dodge the old obstruction: repeated anchors amplify
`sum_s Phi_s`, not the pivot-local maximum, and the Schur-degenerate set is a
max-based local object. But any proof that sums per coordinate, per class, or
per near-degenerate block re-imports the class-count wall. [T1/T2]

**Constants.** Let `C_DRF=2+sqrt(2)`. If a coordinate lift proves

```text
payment_s(D_s) <= f * C_DRF * M_D(s)
```

and transport proves `M_D(s) <= C_tr delta(P)`, then

```text
C_pay = f * (2+sqrt(2)) * C_tr
```

is the constant for the payment horn. If using only the crude pointwise lift,
replace this by `C_pay=2 C_tr`. If the legal-collateral horn has constant
`C_legal`, the resulting `(EX)` constant is

```text
C0 = max(C_pay, C_legal),
```

and the af-validated `lem-factorization` gives

```text
C_sf = 2 C0 + 6.
```

Thus any universal transport constant wins; no part of the downstream chain
requires preserving the original `2`. [T1]

**Recommendation.** Do not af-elevate `conj-degenerate-payment` yet. The next
useful wave should be an arm-D/arm-A structure wave on (TT): exploit row
reproduction and beta stationarity on `D_s`, with the Schur slab as a local
hypothesis, and explicitly test against attempts that sum over coordinates.
The coordinate identities and perturbed-DRF lemma are small enough to formalize
later, but they are support infrastructure, not the gap. [T1/T2]
