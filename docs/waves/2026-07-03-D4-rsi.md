## T1. Exact Import Decomposition

Work in the H-M quotient for a fixed pivot `s`. Let `T={t:t!=s}` and write
`x^+=max(x,0)`, `x^-=max(-x,0)`. For an H-M `B` row `j`,

```text
mu_j    = sum_{t in T} a_t(j)^-,
sigma_j = sum_{t in T} a_t(j)^+,
lambda_j = sum_{t in T} a_t(j) = sigma_j - mu_j.
```

Row reproduction gives, for each transverse coordinate `t`,

```text
a_t(j) = sum_l P_jl a_t(l).                              (R_t)
```

Class rows are import-safe: if `h in C_r`, then `a(h)=e_r`, so
`a_t(h)^-=0` for every `t`. Zero-column H-M rows do not appear in (R_t) because
their columns are zero. Therefore

```text
a_t(j)^-
 <= sum_{l in B} P_jl^+ a_t(l)^-
    + sum_{l in B} P_jl^- a_t(l)^+
    + sum_{h in C_t} P_jh^- .                            (1)
```

Summing (1) over `t in T` gives the named import inequality

```text
mu_j <= I_j + O_B(j) + O_C(j),                            (2)

I_j    = sum_{l in B} P_jl^+ mu_l,             import through B rows,
O_B(j) = sum_{l in B} P_jl^- sigma_l,          own negative entries hitting B positives,
O_C(j) = sum_{r!=s} sum_{h in C_r} P_jh^-,     own negative entries hitting transverse classes.
```

The class-zero statement is exactly the absence of a term
`sum_{h in C_r} P_jh^+ ...`: positive mass on class rows imports no negative
transverse coordinate.

The lambda correction is explicit:

```text
O_B(j) = sum_{l in B} P_jl^- (mu_l + lambda_l)
      <= sum_{l in B} P_jl^- mu_l
         + sum_{l in B} P_jl^- lambda_l^+.                (3)
```

Thus `O_C(j) <= nu_j`, but `O_B(j)` is not just `nu_j` unless one has a
separate bound on the positive transverse mass of the imported `B` rows. In
the reduced fan templates `lambda=0`, so (3)'s lambda correction vanishes.
[T1]

## T2. The B-Block Contraction Question

The only unconditional row-sum estimate is

```text
rho_B(j) <= sum_l P_jl^+ = 1 + nu_j <= 1 + delta(P) <= 5/4.      (4)
```

More precisely, if `c_j^+` is the positive mass of row `j` outside the H-M
`B` block, then

```text
rho_B(j) = 1 + nu_j - c_j^+.
```

So a genuine contraction would require a lower bound
`c_j^+ >= nu_j + epsilon`. The exact examples above often have such a lower
bound, but it is not a theorem. The following exact certificate kills it.
[T1]

## T3. What Remains To Prove

The failed contraction suggests the correct missing statement is not
`rho_B<=1-epsilon`. A better target is the weighted import-excess inequality.
For

```text
A_l := sum_{j in D_s, beta_j>0} beta_j P_jl^+,
```

one needs a bound of the schematic form

```text
sum_{l in B} (A_l - beta_l^+)_+ mu_l
 <= C * (G_class^- + S_-^mu + R_D^nu).                    (WIE)
```

Together with (2), beta stationarity, and the own-source terms, such a lemma
would close (RSI). The B-block refuter above has positive import excess, but
the excess is exactly financed by pivot-class negative aggregate and row
negative mass. That is the cancellation a real proof must use. [T2]

The known dead routes remain off-limits:

- no raw coordinate or class counting;
- no pointwise `mu_j <= C nu_j`;
- no all-row transverse tax without the `D_s`, beta-weighted, argmin package;
- no geometric series from a false `B`-block contraction.
