The Evidence Layer

Numerical results are evidence, never proof (L3). Every bundle carries its re-run command and schema in the repository. Nothing on this page is rigorous, no matter how many instances it covers, and no result below has ever been promoted on the strength of a computation.

A number without a re-run command is not a finding here. Each experiment lands as a bundle: a dated directory holding the script that produced it, the parameters and seeds, the data under a declared schema, a checkable invariant (a known value, an exact certificate, or an independent recomputation), and a README stating the headline finding and its honest scope. A gate refuses any bundle missing those parts. Exact-rational arithmetic is used where the question is combinatorial, so the certificates are exact rather than floating-point — which still makes them evidence, not proof.

The clearest example of the discipline: tens of thousands of exact instances have never violated the standing conjecture, and the conjecture is still tagged conjecture. Below the corner scale the dangerous case has simply never been entered — that is an absence of counterexamples, which is evidence, and is not a proof.

What is deliberately not here

No charts of run data in this build. The interactive δ–H scatter over the certified instance record is a follow-up (it needs the per-instance data exported into the site's data layer, not just the bundle headlines). Plotting it from summary text would be exactly the kind of number-without-provenance this project refuses.

Also absent by design: any statement that a run confirms a conjecture. Runs refute, bound, and fail to refute. The measured relation along the realizable family is linear; the quadratic form people quote is only the worst-case envelope — a distinction the bundles keep and this page will not blur.
